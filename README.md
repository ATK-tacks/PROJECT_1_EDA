# PROJECT_1_EDA
# 🍽️ Zomato Restaurant Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the **Zomato Restaurant Dataset** to uncover meaningful business insights using Python. The analysis includes data cleaning, visualization, and interpretation of restaurant trends such as ratings, cuisines, cities, online delivery, pricing, and customer preferences.

This project was completed as part of an **AI & ML Internship** to demonstrate practical data analysis and visualization skills.

---

## 🎯 Objectives

* Understand the structure and quality of the dataset.
* Clean and preprocess the data for analysis.
* Perform Exploratory Data Analysis (EDA).
* Visualize important trends using different chart types.
* Generate business insights and actionable recommendations.

---

## 📂 Dataset

**Dataset:** Zomato Restaurant Dataset

The dataset contains information about restaurants including:

* Restaurant Name
* City
* Locality
* Cuisines
* Aggregate Rating
* Average Cost for Two
* Votes
* Online Delivery
* Table Booking
* Price Range
* Restaurant Type

## 📊 Project Workflow

### 1. Data Loading

* Imported the dataset using Pandas.
* Explored the dataset structure.
* Examined rows, columns, and data types.

### 2. Data Inspection

* Checked missing values.
* Identified duplicate records.
* Reviewed unique values.
* Generated descriptive statistics.

### 3. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected data types.
* Standardized text columns.
* Removed unnecessary columns where required.

### 4. Exploratory Data Analysis (EDA)

The following business questions were analyzed:

* Which city has the highest number of restaurants?
* Which cuisines are the most popular?
* Which cities have the highest average ratings?
* Does online delivery influence restaurant ratings?
* Does table booking affect customer ratings?
* What is the distribution of restaurant price ranges?
* Which restaurants receive the highest customer votes?

### 5. Data Visualization

The project includes multiple visualizations such as:

* 📊 Bar Chart
* 📈 Line Chart
* 📉 Histogram
* 🔵 Scatter Plot
* 🥧 Pie Chart
* 🔥 Heatmap

Each visualization includes appropriate titles, axis labels, and a brief interpretation.

---

## 💡 Key Business Insights

* A few cities dominate the restaurant market with the highest number of listings.
* Certain cuisines are significantly more popular than others.
* Restaurants offering online delivery generally receive higher customer engagement.
* Mid-priced restaurants represent the largest segment of the market.
* Restaurants with higher customer votes often achieve better ratings.

---

## 📈 Business Recommendations

* Expand operations in high-performing cities.
* Promote restaurants with consistently high ratings.
* Improve online delivery services in underserved locations.
* Focus marketing campaigns on the most popular cuisines.
* Encourage customer reviews and ratings to improve visibility.
